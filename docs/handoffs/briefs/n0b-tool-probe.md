**Steps (each in its own environment, version pinned and recorded):**
1. **OpenBB:** look up the current release first and pin it: `uvx --from openbb-mcp-server==<ver> --with openbb==<ver> openbb-mcp` (default port 8001, localhost only). List the real MCP tool names. Call the SEC income statement, balance sheet, cash flow and risk factors for AAPL, and the Nasdaq earnings calendar and company news. Record: needs a key or not, fields returned, latency, RSS of the process.
2. **AlphaDesk:** `pip install alphadesk` in a fresh venv, run on 127.0.0.1:8000 with only the SEC contact address set (use the Write tool for any settings file, never print it). List the MCP tools it really exposes (README says 53), read the list for anything that writes or sends. Record RSS. It is AGPL-3.0 and has 19 stars: unmodified, separate process, localhost, no vendor keys. Localhost only limits the network; the process can read anything your user account can (home folder, config files). So before running it, skim the source for file and environment reads beyond its own config, or run it in a container or a throwaway user, and record which you did.
3. **TradingAgents:** `uv venv --python 3.13`, then `uv pip install .` (plain `pip` is not seeded in a `uv venv` and could install into the wrong environment) from a pinned release. Configure an OpenAI-compatible endpoint = Aperture (`$APERTURE_URL/v1`, reached over Tailscale, no key needed by us), analyst tier = a cheap alias from `ask --list`. **State the spend before running** and cap it with numbers: `TRADINGAGENTS_MAX_DEBATE_ROUNDS=1`, `TRADINGAGENTS_MAX_RISK_ROUNDS=1`, a low `TRADINGAGENTS_MAX_TOOL_ROUNDS`, the cheapest alias for BOTH tiers, and a worst-case dollar figure written down before the run (calls x max tokens x alias price). Set `deep_think_backend_url`, `quick_think_backend_url` and `backend_url` all to Aperture and confirm from the process's connections that no call goes elsewhere. Then run ONE ticker once, count model calls and tokens, and report the cost per ticker.
4. Verdict per tool: go / no-go / go-with-limits, and which plan pieces it unlocks (N3 data, N4 dropped or kept, N7 budget).
